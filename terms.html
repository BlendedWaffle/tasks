Program description

Tasks is a personal task-management text service. You text a task to +1 (971) 458-1546 and receive a confirmation message that it was added to your task board.

Opting in

Text TASKS to +1 (971) 458-1546, then reply Y to confirm.

Message frequency and costs

Message frequency varies, typically one confirmation per task you add. Message and data rates may apply.

Opting out

Reply STOP at any time to cancel. You’ll receive one final message confirming you’ve been unsubscribed, and no further messages will be sent. Reply START to resubscribe.
